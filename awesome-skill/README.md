# Awesome Team Test Skill Package

Small participant-style package for validating the upload/intake pipeline.

The package is intentionally simple:

- `awesome-pick` selects a valid 11-player roster from the provided board using a specific web-search condition tree and run-level search details
- `awesome-risk-play` always selects one green or red risk play using a separate web-search condition tree

The skills are Markdown instructions only. They require web access during runs so the agent can demonstrate how a searched condition changes player and risk-play decisions. They do not require scripts, credentials, or writing files.
